# Programação Web | Atividades Acadêmicas

Repositório destinado ao armazenamento e à documentação das atividades práticas desenvolvidas na disciplina de **Programação Web**, do curso de **Análise e Desenvolvimento de Sistemas (ADS)** da **Faculdade de Tecnologia de São José dos Campos (FATEC-SJC)**.

## Sobre o Repositório

Este repositório reúne exercícios e projetos acadêmicos voltados ao desenvolvimento de aplicações web, abordando conceitos de frontend, backend, integração com bancos de dados, criação de APIs e comunicação entre cliente e servidor.

As atividades têm como objetivo aplicar os conhecimentos adquiridos em sala de aula por meio da implementação de soluções práticas utilizando tecnologias de desenvolvimento web.

## Projetos e Atividades

### ★ Tarefa 1 — Formulário de Cadastro

Desenvolvimento de uma aplicação web utilizando **Node.js e Express**, responsável por receber e apresentar informações enviadas por meio de um formulário HTML.

**Funcionalidades:**
- Formulário para preenchimento de nome, endereço e telefone.
- Envio dos dados ao servidor utilizando o método HTTP POST.
- Processamento das informações recebidas pelo backend.
- Exibição dos dados cadastrados em uma página HTML.
- Disponibilização de arquivos estáticos por meio do Express.

**Tecnologias:** HTML5, JavaScript, Node.js e Express.

 [Acessar Tarefa 1](./tarefa1)

### ★ CRUD de Produtos — MongoDB

Desenvolvimento de uma aplicação web para gerenciamento de produtos, utilizando operações CRUD (*Create, Read, Update e Delete*) e integração com banco de dados MongoDB.

**Funcionalidades:**
- Cadastro de novos produtos.
- Listagem dos produtos cadastrados.
- Consulta de produtos por identificador.
- Edição e atualização das informações.
- Exclusão de produtos.
- Controle de quantidade disponível em estoque.
- Formatação de preços em reais (R$).
- Validação de formulários e tratamento de erros.

O projeto apresenta uma arquitetura com frontend e backend separados, permitindo a comunicação com o banco de dados por meio de uma API REST.

**Tecnologias:** HTML5, CSS3, JavaScript, Node.js, Express e MongoDB.

 [Acessar CRUD de Produtos](./mongo-crud)

 [Documentação do CRUD](./mongo-crud/README.md)

## Objetivo

Consolidar os conhecimentos teóricos e práticos relacionados ao desenvolvimento web, explorando a construção de interfaces, o processamento de requisições HTTP, a implementação de APIs REST e a persistência de dados em bancos de dados.
